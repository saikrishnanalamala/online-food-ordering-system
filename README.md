# online-food-ordering-system
 The Online Food Ordering System is a database project designed to manage the operations of food delivery platforms like Swiggy / Zomato. It helps to store and manage information about Restaurants, Menu Items, Customers, Orders, and Payments in an organized way using MySQL.  The system reduces manual work and provides fast access .
#Problem Statement:
Develop a database for an Online Food Ordering System that enables customers to browse restaurant menus, place food orders, and make payments. The system should efficiently manage restaurant information, menu items, customer orders, and payment details while generating sales and order reports.
# Objectives of the Project:
- To maintain restaurant information with location and cuisine.
- To store menu details with price and availability.
- To manage customer details and their orders.
- To track payment information like method, amount and status.
- To generate restaurant sales reports.
- To display customer order history.
- To identify popular food items.
  #. Key Features Implemented in Project:
- DDL, DML, String Functions (UPPER, LOWER, SUBSTRING, CONCAT, REPLACE)
- Date Functions (DAYNAME, DATEDIFF, DATE_FORMAT)
- Aggregate Functions (COUNT, AVG, MAX, SUM)
- Joins (INNER JOIN, LEFT JOIN)
- Subqueries & Views (Customer_Order_History, Restaurant_Revenue)
- TCL (Transaction, Savepoint, Rollback, Commit)
- Stored Procedures (Get orders by customer, Total spent by customer)
- Triggers (Orders_Archive on DELETE, Order_Status_History on UPDATE)

#. Conclusion:
This project provides a complete database solution for an online food ordering business. It ensures data integrity using Primary Key and Foreign Key, and helps the admin to analyze business performance, track orders, and improve customer service.
